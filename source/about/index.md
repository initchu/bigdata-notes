## 关于本站

本站系统梳理大数据核心组件的原理与实战要点，覆盖 Hadoop 生态全链路：

| 组件 | 定位 |
|------|------|
| Hadoop | 分布式基础框架 |
| HDFS | 分布式文件存储 |
| MapReduce | 离线批处理计算 |
| YARN | 统一资源调度 |
| ZooKeeper | 分布式协调服务 |
| Hive | SQL 数据仓库 |
| Flume | 日志采集系统 |

内容来源于课程章节精华提炼，每篇文章包含核心原理、架构图解和高频面试题。
